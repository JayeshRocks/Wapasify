# Wapasify

A college-first lost-and-found service: one place to browse reports, suggest possible matches, verify ownership privately, and coordinate safe handover through authorized campus collection points. The name combines “wapas” (back/returned) with a product-style suffix.

## Current status

Prototype in progress. `index.html` is a fictional-data browser demo with simulated search, filters, report forms, and match suggestions. Wapasify is the working brand: initial exact-name web checks returned no relevant product, GitHub, or app-store result, but domain registration and trademark availability still need authoritative checks before public launch.

## Product principles

- Student recovery stays free.
- Show only the details needed to find an item; keep proof-of-ownership clues private.
- Never publish personal phone numbers, student IDs, or exact sensitive locations.
- Route physical returns through a college-approved collection point.
- Keep demo records fictional and label simulated actions clearly.
- Do not connect real student data until staff ownership, access rules, and retention are agreed.
